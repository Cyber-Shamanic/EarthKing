# 👑 EarthKing — מלך הארץ הזאת

**גרסה:** 0.0.6  
**תאריך:** 05.11.2026 · כ״ה בחשוון תשפ״ז  
**יוצר:** לאון יעקובוב (AnLoMinus) — Cyber Shamanic

## הפעלה עצמאית

1. חלץ את ZIP.
2. היכנס לתיקייה הראשית `EarthKing_v0.0.6`.
3. להפעלה מלאה של חלוניות CHANGELOG ו־TODO ושל מזמור המלכות, הפעל שרת מקומי, למשל `python3 -m http.server 8000` מתוך תיקיית הפרויקט, ואז פתח `http://localhost:8000`.
4. שאר פעולות האתר, לרבות הצגת 44 המידות והסימונים, פועלות גם בפתיחת `index.html` ישירות; בפתיחה זו חלק מהדפדפנים יחסמו קריאת קובצי Markdown.

## תכונות

- **20 סטיקרים עצמאיים ב־PNG שקוף ברזולוציה גבוהה**: כל יצירה נוצרה בנפרד, נשמרת בתיקיית `assets/stickers/independent` ומוצגת בגלריית המוזיאון.
- **מקטע ארבעת השערים החדש**: כרטיסיות היכל מלכות עם איור, תרגול, גישה לפרק ומד התקדמות לכל שער.
- **ממשק נשלף ונגיש**: ניווט המבורגר עם תמיכה במקלדת, ופאנל נגישות כאקורדיון עם מחוונים ותפריט גופנים מלא.

- מהדורת CrownForge: 20 סטיקרים מקוריים, ארבעה באנרים וארבעה גב קלף להורדה.
- מוזיאון מלכות אינטראקטיבי, ארבעה שערי לימוד מורחבים (`CHAPTERS.md`) ומד התקדמות לכל שער.
- חלון התאמה קוגניטיבית: שלוש משפחות טיפוגרפיה, גודל, עובי, ריווח שורות והפחתת הילות והנפשות.
- חמש פלטות צבע: זהב, ספיר, פנינה, אזמרגד וארגמן; שמירת הגדרות במכשיר.

- 44 מידות מקוריות, ב־4 שערים (11 בכל שער), וספר חכמה ומלכות עם שאלות ותרגול.
- מזמור מקורי מנוקד ומחורז בארבעה בתים, וחוברת PDF A5 בת 33 עמודים.
- 11 נכסים גרפיים מקוריים: שני רקעים, ארבעה עיטורים וכפתורים, שני צדדי קלפים ושלושה סטיקרים שקופים.
- גלריית נכסים באתר עם סינון, תצוגה מוגדלת והורדת PNG לכל פריט.
- מעבר בין חזית לגב של קלף ובחירת רקע אתר (ארמון או ספרייה).
- חיפוש, סינון, מועדפים, מידה יומית.
- סימון משימות ומד התקדמות.
- קלף נפרד לכל מידה, העתקה ושיתוף.
- יומן רפלקציה מקומי.
- ייבוא וייצוא JSON, הדפסה ומסמכי CHANGELOG/TODO.

## פרטיות

אין התחברות ואין מאגר שרת של משתמשים בגרסה זו. התקדמות, מועדפים ויומן נשמרים ב־localStorage בדפדפן. ניתן לייצא אותם לגיבוי. ניקוי נתוני דפדפן עלול למחוק רשומות שלא גובו.
